# Данные

Все данные синтетические: тексты составлены для хакатона, совпадения с реальными
людьми, номерами и сайтами случайны. Реальных данных клиентов в репозитории нет.

## `dataset/messages.jsonl` — размеченный тестовый набор

Одна JSON-запись на строку:

| Поле | Значение |
|---|---|
| `id` | `<lang>-<label>-NNN`, например `kk-scam-004` |
| `lang` | `ru` или `kk` |
| `channel` | `sms`, `call` (расшифровка звонка), `messenger`, `email` |
| `label` | `scam` или `legit` |
| `scamType` | тип схемы из `src/lib/domain.ts` (`SCAM_TYPES`) для `scam`; `null` для `legit` |
| `split` | `dev` — для настройки правил; `holdout` — только для итоговой оценки |
| `hardNegative` | `true` у обычных сообщений, похожих на мошеннические (уведомления банка с кодами, предупреждения) |
| `text` | текст сообщения или расшифровки |

Правило честной оценки: правила детектора настраиваются только по `dev`;
метрики для README и презентации берутся с `holdout`.

Проверка формата и сводка: `npm run data:check`.

## `dataset/challenge-1.jsonl`, `dataset/challenge-2.jsonl` — независимые наборы

Написаны независимым ревьюером (Codex), который не видел правил детектора: другие сюжеты,
разговорная речь, транслит. `challenge-1` после первого замера использован для доработки
правил. **`challenge-2` — отложенная выборка: по нему правила не настраиваются**, он нужен
для честной оценки (`docs/metrics.md`). Новые примеры для настройки добавляйте в
`messages.jsonl` или в новый файл, но не подгоняйте правила под `challenge-2`.

## `dataset/train-4.jsonl` — казахский набор для разработки

160 синтетических записей с `lang: "kk"` и `split: "dev"`: 100 `scam` и 60 `legit`.
Диапазоны ID: `kk-scam-401`–`kk-scam-500` и `kk-legit-401`–`kk-legit-460`.
Для `code_request` подготовлено 12 примеров, для каждого из остальных восьми типов — 11.
Каналы `sms`, `call`, `messenger`, `email` представлены по 40 записей каждый.
У 40 обычных сообщений стоит `hardNegative: true`: уведомления банка, предупреждения
об обмане, просьбы знакомых о деньгах, доставка и сделки без мошенничества.

Тексты подготовлены и вычитаны Codex: разговорный казахский, смешанная речь RU/KZ,
сокращения и намеренные опечатки. В 51 записи преобладает латиница. Подтверждение
полной вычитки этого набора носителем языка не получено. Ссылки используют только
домены `.example` и `.test`; номера в текстах — вымышленные коды и суммы.
Расшифровки звонков содержат отдельные реплики с `— `, разделённые `\n` внутри JSON.

Набор предназначен для разработки, а не для независимой оценки качества детектора.
Проверка формата: `npm run data:check -- data/dataset/train-4.jsonl`.
