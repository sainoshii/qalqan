Порог мошенничества: `riskScore >= 70`. Все наборы синтетические (см. `data/README.md`).
Замер от 12 ноября 2026, режим **только правила** (без LLM).

| Набор | Кто писал | Роль | Сообщений | Поймано мошеннических | Ложные срабатывания | …на «ловушках» |
|---|---|---|---:|---:|---:|---:|
| `messages.jsonl` (dev) | автор правил | настройка | 57 | 100% | 0% | 0% |
| `messages.jsonl` (holdout) | автор правил | — | 26 | 100% | 0% | 0% |

| **`challenge-2.jsonl`** | независимый ревьюер (Codex) | **честная оценка** | 40 | **10%** | **5%** | 6% |

## Что это значит

- **Правила хорошо ловят известные формулировки и плохо — новые.** На первом независимом наборе
  правила поймали 1 из 20 мошеннических сообщений; после доработки по этому набору — 20 из 20.
  На втором независимом наборе, которого автор правил не видел, — 2 из 20. Перефразировка,
  разговорная речь, транслит и новые легенды обходят регулярные выражения.
- 100% на наборах, по которым правила настраивались, — не показатель качества.
- Поэтому Qalqan — гибрид: правила дают быстрый, бесплатный и объяснимый нижний порог для
  классических схем и защищают от манипуляции моделью, а смысл перефразированных схем должен
  распознавать LLM-слой.
- **Режим «правила + LLM» пока не измерен:** для него нужен ключ Claude API. Команда замера:
  `npm run eval -- --llm --file data/dataset/challenge-2.jsonl`.

## Как воспроизвести

```bash
npm run eval                                              # основной набор
npm run eval -- --file data/dataset/challenge-2.jsonl --verbose
```

`challenge-2.jsonl` — отложенная выборка: по ней правила не настраиваются.
