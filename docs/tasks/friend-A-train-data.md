# Задание для участника A (через Codex): обучающие данные `train-3.jsonl`

Скопируйте всё ниже в Codex, открыв его в своей копии репозитория `qalqan`.

---

Ты пишешь обучающие данные для детектора мошенничества с социальной инженерией в проекте Qalqan.
Прочитай `AGENTS.md`, `CONTRIBUTING.md` и `data/README.md` (формат записей).

**Не открывай и не читай** `src/lib/detector/**`, `data/dataset/challenge-*.jsonl` и
`data/dataset/train-2.jsonl` — данные должны быть независимыми от правил детектора и чужих наборов.

Создай ветку `data/train-3` и файл `data/dataset/train-3.jsonl` — **160 новых сообщений**:

- 80 мошеннических (`label: "scam"`) и 80 обычных (`label: "legit"`);
- в каждой половине не меньше 35 на казахском (`lang: "kk"`), остальные на русском;
- все 9 типов схем из `SCAM_TYPES` в `src/lib/domain.ts` (только этот файл из src можно открыть), минимум по 6 каждого;
- среди обычных не меньше 40 `hardNegative: true`: настоящие уведомления банков, предупреждения о мошенниках,
  бытовые просьбы о деньгах между родственниками и друзьями, сообщения курьеров, маркетплейсов, госуслуг;
- `channel`: sms / call (расшифровка звонка, можно диалог из реплик) / messenger / email;
- `split: "dev"` у всех; id вида `ru-scam-301`, `kk-legit-301` (нумерация с 301 в каждой группе).

Пиши так, как пишут реальные люди: разговорная речь, ошибки, сокращения, смешение русского и
казахского, транслит латиницей, длинные и короткие сообщения, многоходовые звонки. Используй
**разные легенды**: налоговая, ЕНПФ, соцвыплаты, «ошибочный перевод — верните», вакансии с
предоплатой, кредитные брокеры, оператор связи, «замена SIM», доставка, аренда жилья, OLX/Kaspi,
«выигрыш», «компенсация», «блокировка карты», «удалённый доступ», «следователь», «родственник в беде»,
инвестиции и крипта.
Никаких реальных номеров карт, телефонов, ИИН, имён известных людей и настоящих сайтов
(для ссылок используй домены `.example`).

Проверь формат: `npm run data:check -- data/dataset/train-3.jsonl` и `npm run check`.
Сделай коммит и pull request в `main` с описанием: сколько записей, распределение по языкам и типам.
