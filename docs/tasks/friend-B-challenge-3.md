# Задание для участника B (через Codex): независимая проверочная выборка `challenge-3.jsonl`

Скопируйте всё ниже в Codex, открыв его в своей копии репозитория `qalqan`.

---

Ты пишешь **независимую проверочную выборку** для детектора мошенничества с социальной инженерией
в проекте Qalqan. По ней будет считаться честная итоговая цифра качества, поэтому важно, чтобы
тексты не были похожи на то, на чём детектор учился.
Прочитай `AGENTS.md` и `data/README.md` (формат записей).

**Не открывай и не читай** никакие файлы в `data/dataset/` и `src/lib/detector/**`. Из `src` можно
открыть только `src/lib/domain.ts` (список типов схем).

Создай ветку `data/challenge-3` и файл `data/dataset/challenge-3.jsonl` — **80 новых сообщений**:

- 40 мошеннических и 40 обычных; в каждой половине 20 на казахском и 20 на русском;
- все 9 типов схем, минимум по 3 каждого;
- среди обычных не меньше 20 `hardNegative: true` (настоящие уведомления банков, предупреждения о
  мошенниках с цитатами их фраз, бытовые просьбы о деньгах);
- `split: "holdout"` у всех; id вида `ru-scam-401`, `kk-legit-401` (нумерация с 401).

Пиши как реальные люди и реальные мошенники в Казахстане в 2026 году: разговорная речь, ошибки,
транслит, смешение языков, длинные звонки-диалоги, короткие SMS. Придумывай **свои** сюжеты, не
ограничивайся очевидными. Размечай честно по смыслу. Никаких реальных номеров, ИИН и сайтов
(для ссылок — домены `.example`).

Проверь: `npm run data:check -- data/dataset/challenge-3.jsonl` и `npm run check`.
Коммит, pull request в `main`. В описании PR напиши, что файл — отложенная выборка и для обучения
не используется.
